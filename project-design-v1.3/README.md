# شمارا ۱٫۳: بازنگری طراحی برای شروع پیاده‌سازی

**اول `docs/FINAL-HANDOFF.md` را بخوانید.** تصمیم این نسخه: آریا یک اژدهای دوستانهٔ اصیل با اجرای برداری نرم ۲٫۵بعدی است؛ راهنما و آواتار کودک دو نقش مستقل‌اند. چهار تب کودک «مسیر، تمرین، کمد، من» جای پیشنهاد پنج‌تب نسخهٔ قبل را می‌گیرد. این تصمیم طراحی است، نه ادعای تأیید کاربر یا موفقیت آزمون کودک.
پیش‌نمایش منتشرشده: [Shomara Design v1.3](https://app.clickup.com/90141724005/artifact/2kydv3b5-154?version=1)

## چه چیزی واقعاً تحویل شده؟
پیش‌نمایش تعاملی ۲۴ قالب، مسیر شروع/تمرین/نتیجه، چهار پایهٔ آواتار، مو/سبیل/کلاه/لباس/عینک، شش رنگ پوست انسانی، ذخیره/لغو محلی، نتیجهٔ محاسبه‌شدهٔ نمونه، حالت بارگذاری/خالی/خطا و شبیه‌سازی آفلاین. ۲۴ SVG حالت راهنماها، مطالعات حجم آریا، آیکون SVG/PNG و قراردادهای JSON، منابع پژوهش و تست‌های پیش‌نمایش همراه‌اند.

## مرز تحویل
این بسته **طرح و نمونهٔ قابل شروع توسعه** است، نه اپ آمادهٔ انتشار. سورس اصلی تحویل شما تغییر نکرده است. رفع رفتارهای واقعیِ آزموده‌شده مربوط به prototype و هستهٔ کوچک آواتار است؛ ریسک‌های کد اصلی در ممیزی و backlog مشخص‌اند و باید در مرحلهٔ پیاده‌سازی اصلاح شوند.

فایل `.riv`، rig/turnaround نهایی، صدای ضبط‌شده، خرید/ورود واقعی، محتوای کامل پایه‌های ۱ تا ۶ و build آزمودهٔ گوشی در این نسخه وجود ندارد. مطالعهٔ «عمق» آریا هندسهٔ سه‌بعدی یا نمای جانبی production نیست.

## فایل‌های شروع
- `docs/FINAL-HANDOFF.md`: تصمیم قطعی این تحویل، مرزها، فناوری و ترتیب اجرا.
- `docs/DESIGN-HANDBOOK.html` (نسخهٔ PDF تکراری حذف شد): گزارش خواندنی فارسی با مشخصات همهٔ صفحات و شواهد.
- `specs/design-flow.json`: تصمیم فارسی و مسیر هر یک از ۲۴ صفحه.
- `specs/screens.json`: شواهد ایستای نسخهٔ فعلی و یافته‌های ۵۸گانهٔ UX.
- `specs/characters.json`: قرارداد پیشنهادی production؛ با توضیح اصلاحی در handoff خوانده شود.
- `implementation/`: سورس نمونهٔ React و هستهٔ آواتار؛ نه integration در پروژهٔ اصلی.
- `qa/`: پوشش ممیزی، تست‌های نمونه، وضعیت واقعی دارایی و تطبیق حفظ فایل‌های اولیه.
- `prototype/index.html`: در 2.0.5 حذف شد (خروجی build، ۶۴۰KB)؛ نسخهٔ منتشرشده در ClickUp (لینک بالا) یا build از `implementation/prototype-src`.

## اولویت مرجع
`FINAL-HANDOFF.md` و `design-flow.json` تصمیم جاری‌اند. سپس قراردادهای جدید و کد prototype. ممیزی‌های UX/CHARACTER/TECH شواهد و پیشنهادهای پشتیبان‌اند؛ هر تعبیر ناسازگار با handoff مرجع تصمیم نیست. `project-design-v1.2` در 2.0.5 حذف شد (در تاریخچهٔ git موجود است).

پیش‌نمایش فونت Vazirmatn را در صورت دسترسی از Google Fonts می‌گیرد؛ بدون اینترنت از فونت سیستم استفاده می‌کند. فونت تولیدی اپ باید همراه مجوز رسمی داخل اپ بسته‌بندی شود.
