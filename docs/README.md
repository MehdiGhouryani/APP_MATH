# نقشهٔ مستندات

| پوشه | محتوا | کی بخوانم |
|---|---|---|
| `../ROADMAP_PHASES.md` | **منبع حقیقت پیشرفت**: فازها، وضعیت، قدم بعدی | همیشه اول |
| `adr/` | تصمیم‌های معماری (بدون Unity، رویداد معنایی، runtime سمت سرور، طراحی فارسی‌محور) | قبل از تغییر معماری |

| `source/` | specهای محصول، فقط **آخرین نسخهٔ** هر خانواده (+ دو نسخهٔ اصلی که migrationها به نامشان ارجاع می‌دهند) | مرجع محتوا و قوانین |
| `reference/` | ماتریس وابستگی، استاندارد تحویل بسته | گاه‌به‌گاه |
| `history/` | revision noteها و manifestهایی که verify scriptها لازم دارند | فقط تاریخچه |
| `design-history/v1.1/` | تصمیم‌های متنی طراحی v1.1 (قوانین آموزش/پرداخت/حساب/آفلاین که هنوز معتبرند) | وقتی v1.3/v2 ساکت است |
| `CLEANUP_2026-10-02.md` | گزارش پاک‌سازی 2.0.5 | یک بار |
