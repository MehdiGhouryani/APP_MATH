# Phase 4 — Performance Target

## Runtime targets

- Target 60 FPS for standard child interactions.
- Animation should not block answer evaluation or session transitions.
- Character assets are lazy-loaded / cacheable.
- Reduced-motion disables non-essential motion.
- Final validation must include a lower-end Android device before pilot.

## Ownership

Rive owns character/interactive illustration playback.
Reanimated owns React Native layout/UI transitions and lightweight interaction motion.
Learning Engine owns learning decisions.
